Exceptions that are not a `RestException` are mapped to one automatically.

### 1. Mapping

| Status | Exceptions |
|---|---|
| **404** Not Found | `CultureNotFoundException`, `DirectoryNotFoundException`, `DllNotFoundException`, `DriveNotFoundException`, `EntryPointNotFoundException`, `EventLogNotFoundException`, `FileNotFoundException`, `KeyNotFoundException`, `TimeZoneNotFoundException`, `VersionNotFoundException` |
| **400** Bad Request | `ArgumentException` (including `ArgumentNullException` and `ArgumentOutOfRangeException`), `BadHttpRequestException`, `ConstraintException` |
| **403** Forbidden | `AccessViolationException`, `UnauthorizedAccessException` |
| **501** Not Implemented | `NotImplementedException`, `TypeLoadException` |
| **500** Internal Server Error | Anything else, including `InvalidOperationException` |

> Types that inherit from a listed exception are mapped the same way.
>
> The rows are checked from top to bottom. E.g. `CultureNotFoundException` inherits from `ArgumentException`, but results in a 404.

### 2. Response

The exception's `Message` becomes the `detail`, and its type name is added as `originalException`:

```csharp
throw new KeyNotFoundException("The user was not found.");
```

```json
{
  "type": "https://www.rfc-editor.org/rfc/rfc9110.html#name-404-not-found",
  "title": "Not Found",
  "status": 404,
  "detail": "The user was not found.",
  "instance": "/users/12",
  "originalException": "KeyNotFoundException",
  "traceId": "00-f3e52009f0966d717f93c9653ed45e26-750dad4218610f7f-00",
  "method": "GET",
  "requestId": "0HNE94J42PNH8:00000001"
}
```

### 3. Changing the mapping

Register an `IRestExceptionMapper` to map any exception differently. Mappers run before the built-in mapping.

> See [Custom exception mappers](https://github.com/stratisd-labs/rest-exceptions-dotnet/wiki/7.-Custom-exception-mappers).

### 4. Changes

| Version | Change |
|---|---|
| 10.1.0 | `InvalidOperationException` maps to **500** Internal Server Error, instead of 405 Method Not Allowed. |
