There is one simple way to override the default ProblemDetails builder: create your own, implementing our [IRestExceptionProblemDetailsBuilder](https://github.com/stratisd-labs/rest-exceptions-dotnet/wiki/5.-API-reference#irestexceptionproblemdetailsbuilder), and register it as a Singleton.

For example:

### 1. Create the builder

#### Fully custom

```csharp
public class UserIdProblemDetailsBuilder : IRestExceptionProblemDetailsBuilder
{
    public ProblemDetails Build(HttpContext httpContext, RestException restException)
    {
        var problemDetails = new ProblemDetails
        {
            Status = (int)restException.StatusCode,
            Title = restException.Title,
            Detail = restException.Message,
            Type = $"https://www.rfc-editor.org/rfc/rfc9110.html#name-{restException.TypeSuffix}",
            Extensions = new Dictionary<string, object?> {
                { "userId", httpContext.User.FindFirst("Id")?.Value ?? "-" }
            }
        };

        return problemDetails;
    }
}
```

#### Making use of the package's default

```csharp
public class UserIdProblemDetailsBuilder : IRestExceptionProblemDetailsBuilder
{
    public ProblemDetails Build(HttpContext httpContext, RestException restException)
    {
        // Create default ProblemDetails
        var defaultBuilder = new DefaultRestExceptionProblemDetailsBuilder();
        var problemDetails = defaultBuilder.Build(httpContext, restException);

        // Make modifications
        problemDetails.Extensions.Add("userId", httpContext.User.FindFirst("Id")?.Value ?? "-");

        return problemDetails;
    }
}
```

> References:
>
> - [DefaultRestExceptionProblemDetailsBuilder](https://github.com/stratisd-labs/rest-exceptions-dotnet/wiki/5.-API-reference#defaultrestexceptionproblemdetailsbuilder)

### 2. Register as a service

```csharp
builder.Services.AddSingleton<IRestExceptionProblemDetailsBuilder, UserIdProblemDetailsBuilder>();
```

> Ideally, do this before registering the middleware itself.
>
> ```csharp
> builder.Services.AddRestExceptions();
> ```

### Notes to remember

#### 1. Default extension properties

After the builder runs, the following properties are added to every response:

| Property | Behaviour |
|---|---|
| `"instance"` | Always set to the request path. It **cannot** be overridden. |
| `"method"` | Added only if not already present. |
| `"requestId"` | Added only if not already present. |
| `"traceId"` | Added only if not already present. |

So, a `"method"`, `"requestId"` or `"traceId"` set by your builder, or by a `RestException`'s extensions, is kept.
