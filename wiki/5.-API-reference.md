### 1. Abstractions

#### IRestException

Used to enforce the implementation of a default message by all different instances of `RestException`.

```csharp
public interface IRestException
{
    static abstract string DefaultMessage { get; }
}
```

Members:

- `DefaultMessage`: (*static*, *abstract*) Used when the user does not provide a message when throwing an exception. For each `RestException` inheritor class, a generic description of the HTTP error's reference has been provided.

#### RestException

```csharp
public abstract class RestException(string message, Dictionary<string, object?>? extensions) : Exception(message)
{
    public abstract string Title { get; }
    public abstract HttpStatusCode StatusCode { get; }
    public Dictionary<string, object?> Extensions { get; }
    [Obsolete] public string TypeSuffix { get; }
}
```

Members:

- `Title`: (*abstract*) The title of the HTTP error. This defaults to the error's name. E.g. `"Not Found"` when a 404 is thrown.
- `StatusCode`: (*abstract*) The status of the HTTP error. For more details on this, visit [wikipedia](https://en.wikipedia.org/wiki/List_of_HTTP_status_codes).
- `Extensions`: A dictionary used to add custom properties to the resulting `ProblemDetails` response.
- `TypeSuffix`: (*obsolete*) Returns the concatenated string that consists of `StatusCode` and `Title` joined by `"-"` in [kebab case](https://developer.mozilla.org/en-US/docs/Glossary/Kebab_case). It was used to build RFC 9110 links, but those don't exist for every status code. Use [`ProblemTypes.Get(StatusCode)`](#problemtypes) instead.

> References:
>
> 1. [HttpStatusCode](https://learn.microsoft.com/en-us/dotnet/api/System.Net.HttpStatusCode)

#### IRestExceptionMapper

Interface used for mapping additional exception types to a `RestException`.

```csharp
public interface IRestExceptionMapper
{
    RestException? Map(Exception exception);
}
```

Members:

- `Map`: Returns the `RestException` for the given exception, or `null` if the mapper does not handle it.

> See [Custom exception mappers](https://github.com/stratisd-labs/rest-exceptions-dotnet/wiki/7.-Custom-exception-mappers).

### 2. Configuration

#### AddRestExceptions

```csharp
public static IServiceCollection AddRestExceptions(this IServiceCollection services);
public static IServiceCollection AddRestExceptions(this IServiceCollection services, Action<RestExceptionsBuilder> configure);
```

Registers the RestExceptions services. The second overload also configures them, e.g. registers mappers.

#### RestExceptionsBuilder

```csharp
public sealed class RestExceptionsBuilder
{
    public IServiceCollection Services { get; }
    public RestExceptionsBuilder AddMapper<TMapper>() where TMapper : class, IRestExceptionMapper;
}
```

Members:

- `Services`: The service collection RestExceptions is registered in. Useful for extension methods, such as `AddFluentValidation()`.
- `AddMapper<TMapper>`: Registers an `IRestExceptionMapper` as a singleton. Mappers run in registration order. Registering the same mapper type more than once has no effect.

### 3. Utilities

#### RestExceptionFactory

Creates `RestException`s from an `HttpStatusCode`.

```csharp
public static class RestExceptionFactory
{
    public static IReadOnlyCollection<HttpStatusCode> SupportedStatusCodes { get; }
    public static RestException? Create(HttpStatusCode statusCode, string? message = null, Dictionary<string, object?>? extensions = null);
    public static bool TryResolveStatusCode(string? value, out HttpStatusCode statusCode);
}
```

Members:

- `SupportedStatusCodes`: The status codes that a `RestException` exists for.
- `Create`: Creates the `RestException` for the given status code, or returns `null` if none exists. When `message` is `null`, the exception's default message is used.
- `TryResolveStatusCode`: Resolves a supported status code from text. Matching is case-insensitive and accepts:
  - the numeric code, e.g. `"409"`
  - the `RestException` type name, with or without its suffix, e.g. `"ConflictRestException"` or `"Conflict"`
  - the `HttpStatusCode` member name, e.g. `"UnprocessableEntity"`

```csharp
var exception = RestExceptionFactory.Create(HttpStatusCode.Conflict, "The user already exists.");

if (RestExceptionFactory.TryResolveStatusCode("Conflict", out var statusCode))
{
    // statusCode == HttpStatusCode.Conflict
}
```

#### ProblemTypes

Resolves the `type` of a problem details response from its status code.

```csharp
public static class ProblemTypes
{
    public const string AboutBlank = "about:blank";
    public static string Get(HttpStatusCode statusCode);
}
```

Members:

- `Get`: Returns a link to the RFC section that defines the status code, e.g. `"https://www.rfc-editor.org/rfc/rfc9110.html#section-15.5.5"` for 404 or `"https://www.rfc-editor.org/rfc/rfc6585.html#section-4"` for 429. Status codes without a `RestException` get `AboutBlank`, which [RFC 9457](https://www.rfc-editor.org/rfc/rfc9457.html#name-aboutblank) uses for problems that mean no more than their status code.

> RFC 9457 says that when `type` is `about:blank`, `title` should be the HTTP status phrase. If a custom `RestException` uses a status code without a `RestException` and its own `Title`, [override the builder](https://github.com/stratisd-labs/rest-exceptions-dotnet/wiki/4.-Override-ProblemDetails-builder) to give it its own `type`.

#### ExceptionExtensions

```csharp
public static class ExceptionExtensions
{
    public static RestException MapToRestException(this Exception exception);
    public static RestException MapToRestException(this Exception exception, IEnumerable<IRestExceptionMapper> mappers);
}
```

Members:

- `MapToRestException(exception)`: Applies the [built-in exception mapping](https://github.com/stratisd-labs/rest-exceptions-dotnet/wiki/6.-Built-in-exception-mapping).
- `MapToRestException(exception, mappers)`: Tries the given mappers first, in order, then falls back to the built-in mapping.

#### ValidationExceptionMapper

```csharp
public sealed class ValidationExceptionMapper : IRestExceptionMapper
{
    public const string ErrorsExtensionKey = "errors";
    public const string MultipleFailuresMessage = "One or more validation errors occurred.";

    public RestException? Map(Exception exception);
}
```
